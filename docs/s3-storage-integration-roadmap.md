# Роадмап интеграции с S3-хранилищами

## Цель

Добавить в PayPlanner подключение нескольких S3-совместимых хранилищ, начиная с полной совместимости с HOSTKEY S3, а затем использовать эти подключения для автоматической выгрузки резервных копий базы данных.

## HOSTKEY S3

По документации HOSTKEY подключение выполняется как к S3-compatible storage:

- endpoint: `https://s3-nl.hostkey.com`;
- region: `nl`;
- протокол: HTTPS;
- авторизация: AWS Signature Version 4;
- учетные данные: Access Key и Secret Key из панели HOSTKEY;
- работа идет с bucket и object key/prefix.

## Этап 1. Подключения S3

- Готово: создать ветку `feature/s3-storage-hostkey` от обновленной `main`.
- Готово: добавить backend-модель нескольких S3-подключений в `SystemSettings`.
- Готово: добавить HOSTKEY preset с endpoint `https://s3-nl.hostkey.com` и region `nl`.
- Готово: не возвращать Secret Key в API, показывать только masked preview.
- Готово: добавить проверку подключения через list, upload, download и delete служебного файла.
- Готово: закрепить поведение backend-тестами.

## Этап 2. Права, аудит и UI

- Готово: добавить отдельный раздел прав `S3Storage` в интерфейс настройки ролей.
- Готово: добавить раздел "S3-хранилища" в интерфейс администратора.
- Готово: реализовать список подключений, создание, редактирование, удаление и кнопку "Проверить".

- Готово: записывать аудит изменения подключений и проверки доступа.
