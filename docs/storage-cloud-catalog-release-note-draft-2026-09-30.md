# Черновик «Что нового»: подтверждение облачной резервной копии

Пока не добавлен в опубликованные записи. Войдёт в выбранную владельцем общую запись или отдельную запись после решения о формате.

Название: Надёжнее подтверждение облачной копии

Кратко: Резервная копия на S3 или Яндекс.Диске больше не отмечается проверенной, если сведения о её составе изменились во время отправки.

- Исправлено: При завершении облачной загрузки система повторно сверяет описание комплекта с записью в каталоге. Если они различаются, попытка показывается как неудачная и копия не считается готовой для восстановления.
- Важно: Уже созданная локальная копия при таком отказе сохраняется. Облачную отправку можно повторить после устранения причины несовпадения.
