# Адаптивная компоновка раздела «Дела»

Документ фиксирует проверенный контракт интерфейса реестра и карточки дела. Он нужен, чтобы новые поля и действия не возвращали горизонтальную прокрутку всей страницы и не перекрывались боковым меню.

## Проверенные поверхности

- реестр дел и его фильтры;
- выбор физического или юридического владельца;
- форма создания и редактирования дела;
- быстрые поля статуса, стадии, приоритета и ответственного;
- вкладки «Обзор», «Участники», «Задачи», «Суд», «Финансы», «Заказ-наряд», «Документы», «Переписка» и «История»;
- формы судебных сторон, событий и процессуальных сроков;
- загрузка документов и фильтры версий.

## Правила компоновки

1. При ширине окна от 1024 пикселей боковое меню постоянно видно, а рабочая область получает равный его ширине левый отступ. На ширине до 1023 пикселей меню скрыто и открывается поверх страницы отдельной кнопкой.
2. Верхняя панель на мобильном экране оставляет место для кнопки меню. Длинное название раздела сокращается внутри своей области и не выталкивает кнопки уведомлений и профиля.
3. Быстрые настройки карточки используют четыре колонки только при достаточной ширине рабочей области. Поля автоматически переходят на две или одну колонку без фиксированной минимальной ширины страницы.
4. Плотные формы судебного блока и документов используют две колонки на обычном desktop/tablet и переходят в одну широкую строку полей только от breakpoint `2xl`.
5. Панель области реестра переносит кнопки на новую строку на телефоне. Сохранённые представления располагаются отдельной строкой, пока ширины рабочей области недостаточно для общей горизонтальной панели.
6. Широкие рабочие таблицы прокручиваются только внутри собственного контейнера. Горизонтальная прокрутка документа считается дефектом.

## Матрица проверки

| Ширина | Назначение | Ожидаемый результат |
| --- | --- | --- |
| 1440 px | desktop | вся карточка доступна без прокрутки страницы по горизонтали |
| 1280 px | компактный desktop | все девять вкладок и формы остаются в рабочей области |
| 1024 px | tablet / граница `lg` | меню не перекрывает страницу, плотные формы переносятся |
| 390 px | телефон | меню скрыто, заголовок не перекрыт, поля идут одной колонкой |

После изменения сеток, бокового меню или верхней панели необходимо повторить эту матрицу в браузере и проверить консоль. Перезагрузка страницы во время разработки может штатно прервать текущую SignalR-negotiation; после стабилизации страницы новые ошибки появляться не должны.
