## Предлагаемый текст после квалификации полного механизма

**Заголовок:** Новая попытка загрузки документа дела

**Описание:** Незавершённую загрузку можно явно прекратить перед отправкой нового файла.

- **new:** В состоянии загрузок обеих карточек дела можно прекратить свою прежнюю попытку после подтверждения. Действие доступно также для новой версии документа и скана исполнительного листа.
- **improved:** Если прежняя попытка уже добавила документ, CRM покажет подтверждённый результат и сохранит документ. Новый выбранный файл отправляется отдельным действием.
- **important:** При обрыве связи CRM сначала проверяет результат прекращения. Пока результат не подтверждён, прежняя попытка остаётся сохранённой для проверки. Прекращение попытки не удаляет уже добавленные документы.
