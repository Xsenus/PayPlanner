# Единый roadmap незакрытых работ

Дата объединения: 8 июня 2026.
Дата детальной сверки по коду: 8 июня 2026.

Этот документ заменяет старые roadmap и plan-файлы. В него перенесены только работы, которые по текущему состоянию проекта не подтверждены как полностью выполненные. Пункты, закрытые кодом, тестами и не требующие ручной приемки, сюда не переносятся.

## Статусы

- `[acceptance]` код найден, остается ручная приемка на реальных ключах, реальных данных или окружении заказчика.
- `[partial]` часть механизма найдена в коде, но сценарий из roadmap закрыт не полностью.
- `[todo]` реализации по коду не найдено или найден только смежный механизм.
- `[decision]` нужно решение заказчика или внешний артефакт, без него реализацию нельзя корректно завершить.

## Правила ведения

- Добавлять сюда только незакрытую работу.
- После полной реализации и приемки пункта удалять его из этого файла, а не оставлять как выполненный чекбокс.
- Если задача требует решения заказчика, сначала фиксировать вопрос в разделе "Открытые решения".
- Пользовательские изменения сопровождать записью в "Что нового".
