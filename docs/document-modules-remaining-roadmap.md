# Roadmap: счета, акты, договоры, банк и касса

Дата фиксации: 2026-05-02

Источник: `C:\Users\ilel\Downloads\МОДУЛИ СЧЕТА - АКТЫ - ДОГОВОРЫ - ЖУРНАЛЫ КАССА И БАНК.docx`

## Цель

Закрыть оставшиеся требования по модулям:

- счета;
- акты;
- договоры;
- банк-журнал;
- банк/касса.

Текущий фундамент уже есть: CRUD счетов, актов и договоров, рассрочка, печатные формы счетов и актов, email-отправка счетов и актов, журнал денег, импорт банковской выписки, ПКО/РКО, кассовая книга и журнал кассовых документов.

Ниже перечислено только то, чего не хватает или что реализовано не в полном бизнес-сценарии из ТЗ.

## Принципы реализации

- Идти небольшими этапами, каждый этап должен давать видимую пользовательскую ценность.
- Сначала закрыть статусы и жизненный цикл документов, потом автоматические каскады и отчеты.
- Не ломать текущую модель `Payment`/`Invoice`: вводить недостающие поля и workflow постепенно.
- Все изменения с БД делать миграциями для SQLite и PostgreSQL.
- Каждый этап считать готовым только если есть backend, frontend, тесты и понятное поведение в UI.

## Definition of Done

Каждый пункт roadmap считается завершенным, если:

- [ ] реализован backend;
- [ ] реализован frontend;
- [ ] добавлены миграции SQLite и PostgreSQL, если менялась БД;
- [ ] добавлены или обновлены тесты;
- [ ] проверена сборка frontend;
- [ ] проверены backend-тесты;
- [ ] обновлены русские тексты UI;
- [ ] сценарий понятен пользователю без ручной правки данных;
- [ ] изменения не ломают существующие счета, акты, договоры, платежи и кассовые документы.
