# Черновик «Что нового»: защита локального хранилища

Пока не добавлен в опубликованные записи; формат общего выпуска ожидает решения владельца.

Название: Дополнительная защита файлов CRM

Кратко: Локальное хранилище отклоняет обращение через ссылку на папку или файл за пределами настроенного каталога.

- Исправлено: При загрузке, чтении, проверке и удалении файлов путь проверяется на вложенные ссылки. Если такая ссылка найдена, операция прекращается до обращения к файлам за пределами хранилища.
- Важно: Для обычной работы ничего менять не требуется. Если каталог хранилища вручную заменён ссылкой на другую папку, операция остановится с ошибкой.
