# Черновик записи «Что нового»: выбор счёта для выписки

Статус: локальный черновик, не опубликован. Адресные проверки компонента и запросов API, lint и TypeScript пройдены; полный выпускной прогон и проверка на сервере ещё не выполнялись. Номер версии будет назначен при включении в выпуск.

**Заголовок:** Выписка по выбранному банковскому счёту.

**Краткое описание:** Загрузка выписки и проверка папки используют банковский счёт и компанию, выбранные в разделе «Деньги → Банк».

**Исправлено:** В разделе «Деньги → Банк» загрузка выписки и запуск подгрузки из папки используют банковский счёт, выбранный в заголовке, и его собственную компанию. Если выбраны все счета или счёт недоступен для новых операций, сначала нужно выбрать действующий счёт. Одинаковые названия счетов разных компаний не мешают выбрать нужный счёт.

**Улучшено:** Пока загрузка или проверка папки выполняется, повторный запуск и смена счёта недоступны. Если выбор счёта или права изменились во время выбора файла, файл нужно выбрать заново. После завершения загрузки журнал обновляется по текущему поиску и фильтрам.

Этот шаг исправляет передачу выбранного счёта в существующий импорт. Общий предварительный просмотр выписки и ручное распределение между документами остаются открытыми задачами BANK-02/03/04. Прогресс полного банковского роадмапа остаётся 0/12 (0%).
