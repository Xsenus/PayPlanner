# Архив roadmap

Эта папка хранит подробные исторические roadmap, которые больше не являются рабочими планами.

Актуальные рабочие roadmap находятся только в корне `docs/`. Новые задачи, незакрытые пункты, ручную приемку и решения заказчика нужно фиксировать в активных roadmap из `docs/`, а не в этой папке.

Архивные файлы оставлены для истории: в них можно посмотреть детали реализации, проверки и старые решения, но не нужно открывать их перед началом новой работы, если только конкретная задача прямо не требует исторического контекста.

Если roadmap закрывается или ставится на паузу по решению пользователя, его нужно переносить сюда и больше не использовать как рабочий план.
