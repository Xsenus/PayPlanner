# Архив roadmap

Эта папка хранит подробные исторические roadmap, которые больше не являются рабочими планами.

Актуальная единая карта проекта находится в `docs/remaining-roadmap.md`. Новые задачи, незакрытые пункты, ручную приемку и решения заказчика нужно фиксировать там.

Архивные файлы оставлены для истории: в них можно посмотреть детали реализации, проверки и старые решения, но не нужно открывать их перед началом новой работы, если только конкретная задача прямо не требует исторического контекста.
