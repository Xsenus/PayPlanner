## Next lifecycle testability seams

- Add a tiny injectable timer/delay abstraction for `BackgroundService` loops that currently wait from minutes to days.
- Promote private tick methods such as `PaymentStatusUpdater.TickAsync` to internal/public testable `RunOnceAsync` methods when behavior is already deterministic.
- Build fake integration boundaries for Google Calendar, Yandex Calendar, Telegram polling, and court sync before direct lifecycle tests are allowed to run.
- Keep external API calls disabled in lifecycle tests unless the dependency is fully fake.
