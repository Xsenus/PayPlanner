# Мессенджер PayPlanner по требованиям YouGile

## Цель

Реализовать внутри PayPlanner рабочие чаты уровня, описанного в задаче PAY-1 компании PayPlanner в YouGile: чат задачи, командные каналы и личные диалоги, с файлами, ответами, реакциями, упоминаниями, поиском, уведомлениями и строгим доступом участников. Изменения в карточке задачи должны одинаково работать в старом и новом интерфейсе.

## Прогресс

- Всего пунктов: 27.
- Завершено: 25.
- В работе: 1.
- Заблокировано / требует решения / приемки: 1.
- Готовность: 93%.

## Требования и реализация

- [x] Изучить описание и обсуждение PAY-1 только в компании PayPlanner в YouGile.
- [x] Скачать production-БД с VPS, проверить контрольную сумму, восстановить в отдельную локальную БД и отключить в копии внешние отправки.
- [x] Спроектировать сущности чатов, участников, сообщений, файлов, реакций и состояний прочтения с индексами и ограничениями.
- [x] Добавить миграции SQLite и PostgreSQL и проверить чистую установку и обновление production-копии.
- [x] Реализовать чат задачи с автоматическим доступом участников задачи.
- [x] Реализовать командные каналы и управление их участниками.
- [x] Реализовать личный диалог строго между двумя пользователями без дублей.
- [x] Реализовать сообщения, редактирование и мягкое удаление только своих сообщений.
- [x] Реализовать ответы, реакции, упоминания и закрепление не более трех сообщений.
- [x] Реализовать безопасные вложения с проверкой доступа, размера и типа.
- [x] Реализовать курсорную загрузку по 50 сообщений и поиск по тексту, автору, дате и упоминанию. Текстовый поиск запускается по «Найти»/Enter без запроса на каждую букву; запоздалый ответ прежней загрузки не заменяет новый результат.
- [x] Реализовать отметку прочтения и счетчики непрочитанных: отметка принимается только для сообщения выбранного чата, а просмотр результатов поиска не сбрасывает непрочитанные сообщения вне результата.
- [x] Реализовать настройки уведомлений «все / упоминания / отключены» и уведомления об ответах, упоминаниях и созданных из сообщений задачах.
- [x] Реализовать обновления SignalR не позднее 10 секунд и системные сообщения об изменении статуса и исполнителя задачи.
- [x] Реализовать создание задачи из сообщения и обратную ссылку на нее в чате.
- [x] Добавить раздел «Мессенджер» с адаптивным интерфейсом, группировкой по датам и доступными действиями.
- [x] Добавить вкладку «Чат» в обе карточки задачи и проверить настройку выбора карточки администратором.
- [x] Отображать имена вместо технических номеров упоминаний и показывать участников в заголовке чата задачи.
- [x] Передавать время чата с признаком UTC и группировать сообщения по местной дате сотрудника, в том числе около полуночи.
- [x] Добавить backend- и frontend-тесты на права, негативные сценарии, границы, поиск и основные пользовательские потоки.
- [x] Добавить понятную запись в «Что нового» и выполнить финальные проверки backend, frontend, сборки и кодировки.
- [x] Добавить отдельные приглашения в чат задачи, не выдающие прав на саму задачу; постановщик управляет приглашёнными, отзыв сразу закрывает чтение сообщений и файлов.
- [x] Добавить личное скрытие и архив чата без удаления чужой переписки; скрытый чат возвращается с новым сообщением, архивный сохраняет непрочитанные.
- [x] Разделить список чатов по типам и архиву, подсветить непрочитанные, сделать ширину списка регулируемой.
- [x] Сделать название и упоминания номеров задач переходами к карточкам; пояснить видимость ответов и упоминаний и показывать имена прочитавших.
- [~] Проверить новые сценарии доступа, обе карточки задачи, миграции, сборку и локальный интерфейс; обновить «Что нового» и комментарий PAY-1.
- [acceptance] Провести ручную приемку уведомлений, мобильного вида и сценария двух одновременно подключенных пользователей.

Новые пожелания PAY-1 от 24 сентября уточнены с заказчиком: приглашённые сотрудники участвуют только в чате задачи; скрытие и архив действуют лично для пользователя, без удаления сообщений у коллег.

Дополнительная проверка синхронизации выявила, что обычное редактирование задачи отзывает приглашение гостя чата. Исправлено: приглашение сохраняется после обновления задачи, ранее отозванное не восстанавливается. Добавлен серверный регрессионный тест; локальная визуальная проверка и ручная приёмка двумя пользователями остаются открытыми.

## Связанные задачи YouGile

- PAY-1 — текущая реализация мессенджера.
- PAY-2 содержит только название раздела «Зарплата» без постановки и критериев приемки, поэтому не включена в реализацию до появления требований.
- PAY-3 сопоставлена с действующей дорожной картой `docs/tz-gap-court-providers-roadmap-2026-07-29.md`: интерфейс судебного раздела уже реализован, а внешние провайдеры требуют согласованных тестовых дел, фикстур и правомерного доступа.

## Определение готовности

Функция считается готовой после прохождения автоматических тестов, миграций на чистой и восстановленной production-БД, проверки обеих карточек задачи, отсутствия ошибок браузера и сервера, а также ручной проверки доступа и доставки событий между двумя пользователями.
