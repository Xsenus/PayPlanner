## Проблема клиента

В задаче нельзя нормально добавить нескольких согласующих и наблюдателей, удалить их, скорректировать список и увидеть, кто уже выбран. По описанию клиента ожидается выпадающий список с кнопки, а выбранные лица должны отображаться под кнопкой.

## Целевое решение

Управление согласующими и наблюдателями должно работать как понятный multi-select:

- кнопка открывает список сотрудников;
- можно выбрать несколько пользователей;
- выбранные участники отображаются под кнопкой;
- каждого выбранного можно удалить;
- при повторном открытии видно, кто уже добавлен;
- сохранение корректно работает в старой и новой карточке задачи.

## Рабочие пункты

- `[ ]` Провести аудит текущих полей согласующих и наблюдателей в старой и новой карточке задачи, API сохранения и нормализации payload.
- `[ ]` Исправить добавление нескольких согласующих без потери уже выбранных пользователей.
- `[ ]` Исправить добавление нескольких наблюдателей без потери уже выбранных пользователей.
- `[ ]` Добавить видимый список выбранных согласующих под кнопкой выбора с возможностью удаления.
- `[ ]` Добавить видимый список выбранных наблюдателей под кнопкой выбора с возможностью удаления.
- `[ ]` Исправить редактирование существующей задачи: открытие должно показывать текущих участников и сохранять изменения без сброса.
- `[ ]` Покрыть тестами создание, редактирование, удаление, повторное открытие и сохранение участников в обеих карточках задачи.
- `[acceptance]` Проверить вручную на локальной БД: несколько согласующих и наблюдателей добавляются, видны, удаляются и сохраняются после перезагрузки.

## Definition of Done

- Пользователь видит всех выбранных согласующих и наблюдателей до сохранения и после повторного открытия задачи.
- Можно добавить и удалить несколько участников без обходных действий.
- Сохранение не ломает согласование, наблюдение, уведомления и права доступа.
- Добавлена запись в "Что нового".
