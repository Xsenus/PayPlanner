## Проблема клиента

В задаче нельзя нормально добавить нескольких согласующих и наблюдателей, удалить их, скорректировать список и увидеть, кто уже выбран. По описанию клиента ожидается выпадающий список с кнопки, а выбранные лица должны отображаться под кнопкой.

## Целевое решение

Управление согласующими и наблюдателями должно работать как понятный multi-select:

- кнопка открывает список сотрудников;
- можно выбрать несколько пользователей;
- выбранные участники отображаются под кнопкой;
- каждого выбранного можно удалить;
- при повторном открытии видно, кто уже добавлен;
- сохранение корректно работает в старой и новой карточке задачи.

## Definition of Done

- Пользователь видит всех выбранных согласующих и наблюдателей до сохранения и после повторного открытия задачи.
- Можно добавить и удалить несколько участников без обходных действий.
- Сохранение не ломает согласование, наблюдение, уведомления и права доступа.
- Добавлена запись в "Что нового".
