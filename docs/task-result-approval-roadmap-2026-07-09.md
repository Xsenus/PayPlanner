## Проблема клиента

При отправке отработанной задачи на согласование исполнитель может отправить ее без результата. Клиент ожидает всплывающее окно для внесения результата задачи у исполнителя и принудительное окно у согласующего.

## Целевое решение

Отправка задачи на согласование должна требовать понятный результат работы:

- исполнитель нажимает отправку на согласование;
- CRM показывает окно ввода результата задачи;
- без результата отправить нельзя;
- согласующий получает принудительное окно с результатом, задачей и действиями;
- решение согласующего сохраняется в истории и уведомляет исполнителя.

- `[ ]` Добавить или усилить backend-валидацию: задача не переходит на согласование без результата работы.
- `[ ]` Сделать окно ввода результата при отправке на согласование в старой карточке задачи.

- `[ ]` Добавить принудительное окно согласующего с результатом, контекстом задачи и действиями согласовать/вернуть на доработку.
- `[ ]` Зафиксировать результат и решение согласующего в истории задачи и уведомлениях.
- `[ ]` Покрыть тестами обязательность результата, отправку, согласование, возврат на доработку, старую и новую карточку.
- `[acceptance]` Проверить вручную на локальной БД: исполнитель не может отправить пустой результат, согласующий видит окно и может принять или вернуть задачу.

## Definition of Done

- Отработанная задача не уходит на согласование без результата.
- Согласующий не пропускает результат: он видит принудительное окно и понятные действия.
- История задачи показывает результат, отправителя, согласующего и решение.
- Добавлена запись в "Что нового".
