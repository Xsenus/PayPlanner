## Следующая очередь

Результат контроля аванса через обычный Update требует отдельной проверки: текущий этап ограничивает начальное создание, а не все последующие переходы. Следом воспроизвести попытки подставить возврат/исключение/распределение через Update и сопоставить их с существующими специальными действиями, правами и денежной историей. CanEdit не является доказательством совершённого возврата. Немедленные уведомления V1 остаются отдельной границей совместимости.

Обнаруженный дополнительный остаток: старые человекочитаемые подсказки частичной оплаты ещё используются при восстановлении исторического переноса. Их нельзя удалить из входа без замены нынешнего fallback-потока формы. Они остаются отдельной обязательной границей вместе с keyless Create/неизвестным commit, snapshot-политикой старого Create и историческим долгом; текущий этап не объявляет весь финансовый ввод закрытым.

Далее callbacks/матрица CMP и Linux native/реальная приёмка изображений и документов. CMP-05/SEC-01/DOC-09 остаются открытыми. Один полный обязательный CI семи jobs перед выпуском; сейчас адресные проверки, успешные без изменения влияющих входов не повторять. Последняя сверка чатов, без публикаций/push/merge/VPS/установщика/другого выпуска.
