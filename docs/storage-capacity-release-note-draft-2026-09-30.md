# Черновик «Что нового»: контроль места при загрузке

Ожидается решение, объединить изменения в одну запись или разделить. До решения этот текст не добавлен в активные записи «Что нового».

## Общая запись

Название: Контроль места при загрузке файлов

Кратко: Для загрузки файлов задач и фотографий подготовлена дополнительная проверка свободного места и безопасная сверка незавершённых резервов.

- Улучшено: Когда администратор отдельно включает проверку места, загрузка учитывает временный файл, основную копию и совместимые файлы задачи, дела или фотографии на одном диске. При нехватке места или невозможности надёжно определить его объём новая копия не создаётся. По умолчанию эта проверка выключена и пока не охватывает все способы сохранения файлов в CRM.
- Новое: В настройках «Хранилище файлов» администратор видит отдельно общее число незавершённых резервов и число резервов временных файлов. Для ручного разбора показаны причина, относительный путь и ожидаемый/найденный размер; небезопасный путь не раскрывается. Сначала можно просмотреть записи без изменений; отдельное подтверждение освобождает только резерв, для которого повторно найден полный файл в ожидаемом каталоге на том же диске. Неполные и отсутствующие файлы не удаляются.
- Исправлено: Записи без найденного размера или безопасного пути теперь отображаются без ошибки и остаются в списке для ручного разбора.
- Исправлено: Если на сервере недоступно место для временной проверки скачиваемого файла, система больше не принимает это за повреждение его копии в хранилище. Скачивание останавливается без изменения состояния копии; после восстановления места его можно повторить.
- Исправлено: При загрузке фото профиля и файла во внутренний чат новая копия больше не может перезаписать существующий файл с тем же служебным именем. Если передача прервалась, её неполный файл удаляется; ранее сохранённые файлы остаются на месте.
- Исправлено: Во внутреннем чате сообщение с файлами появляется только после успешного сохранения всех вложений. Если отправка сорвалась до сохранения сообщения, его и новой активности в чате не будет, а файлы этой попытки убираются. При сбое уже после сохранения сообщение и его файлы сохраняются вместе.
- Исправлено: В переписке дела сбой загрузки одного из нескольких вложений не оставляет ранее загруженные файлы и не публикует сообщение. Сбой оповещения после сохранения больше не удаляет приложенный документ: запись и её файл остаются вместе.
- Исправлено: При замене фото профиля неоднозначная ошибка сохранения больше не удаляет новую фотографию, на которую уже мог сохраниться адрес в профиле. Если не удалось убрать прежнее фото, новая фотография остаётся доступной.
- Важно: Резерв, оставшийся более десяти минут, отмечает состояние хранилища как проблемное. Кратковременный резерв выполняющейся загрузки не считается аварией. Автоматической очистки подозрительных файлов и общего контроля всех внешних хранилищ пока нет.
