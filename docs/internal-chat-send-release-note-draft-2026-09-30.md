# Черновик «Что нового»: повторная отправка сообщений

Ожидается решение о формате записи «Что нового». Этот текст пока не добавлен в опубликованные записи.

Название: Надёжная отправка сообщений в чате

Кратко: Повторное нажатие «Отправить» после ошибки связи больше не создаёт второе одинаковое сообщение.

- Улучшено: В чате задачи и внутреннем мессенджере повторная отправка того же черновика использует прежний идентификатор. Если сообщение уже сохранилось, чат возвращает его вместо создания копии; при изменении текста или файлов начинается новая отправка. Идентификатор сохраняется в текущей вкладке при переходе между чатами.
- Исправлено: Если сообщение с вложениями сохранено, а последующее оповещение временно не удалось, пользователь получает результат отправки; файл остаётся прикреплённым. Если само сохранение прервалось, новое сообщение не появляется.
- Исправлено: Если после сохранения сообщения уведомление участнику чата временно не создалось, система повторит попытку в фоне. Повтор не создаёт второй экземпляр самого сообщения.
- Исправлено: Временная ошибка уведомления больше не мешает остальным участникам увидеть обновление чата и связанных задач в открытом интерфейсе.
- Важно: Старые открытые версии интерфейса, которые ещё не передают идентификатор отправки, продолжают работать, но повтор после неоднозначной ошибки связи для них может создать дубль. После обновления страницы используется новая защита.

Ограничение текущей реализации: восстановление гарантирует повторную попытку создания уведомления внутри CRM; отдельная внешняя доставка (MAX/Web Push) после уже созданного уведомления использует существующий механизм очереди и здесь не переопределяется.
