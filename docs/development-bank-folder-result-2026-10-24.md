# Результат ручной подгрузки банковских выписок из папки

Статус: локальный черновик. Код и регрессии подготовлены в отдельном worktree. Пройдены 11 новых адресных проверок результата папки, scoped ESLint двух файлов и одна общая проверка типов приложения по снимку 634 неизменных входов, включающему банковский пакет и карточку клиента. В основной репозиторий и на сервер изменения не переносились. Прежние 28 адресных успешных проверок выбора счёта относятся к сохранённому кандидату и не объявляются полной квалификацией этого изменённого пакета.

## Изменение

В разделе «Деньги → Банк» результат ручной кнопки «Проверить» показывает уже полученные от сервера ошибки выписок. Нормальный результат без ошибок сохраняет прежнее уведомление об успехе. При ошибках и созданных операциях показан частичный результат: созданные операции сохранены, другие файлы или строки требуют внимания. Если операций не создано, результат сообщает об ошибках без уведомления об успехе.

В блоке результата доступны первые пять ошибок, их полное число и число оставшихся ошибок. Текст содержит имя файла, уже добавленное сервером; ошибки отдельных файлов повторно не собираются и не дублируются. Текст выводится обычным безопасным текстом, без выполнения HTML. Результат доступен для чтения вспомогательными средствами.

Запросы, серверный контракт, права, выбранная компания и счёт, защита повторного запуска и поздних ответов не меняются. При созданных операциях журнал по-прежнему обновляется по текущим фильтрам. Частичный результат не означает отмену или откат уже созданных операций. Дополнительные сетевые запросы не добавляются.

## Подготовленные адресные регрессии

- Два обычных результата без ошибок: ноль и несколько созданных операций.
- Частичный результат и результат без созданных операций при одной, пяти и шести ошибках: видны не более пяти, счётчик остатка точен.
- Только общий массив ошибок, без повторного добавления ошибок отдельных файлов; HTML остаётся текстом.
- Следующая успешная проверка заменяет прежние ошибки.
- Ответ с ошибками после отзыва права не раскрывается; при созданных операциях сохраняется текущий поиск, при нуле нет лишней перезагрузки.

Все 11 новых случаев прошли (native exit 0); 103 посторонних случая файла не запускались. Scoped ESLint и общая проверка типов завершились с native exit 0. Красный снимок прежнего компонента с новыми регрессиями сохранён, но не выполнялся; воспроизведение падения не заявляется. Полные frontend/backend проверки, сборка, браузер и HTTP-smoke этого пакета не запускались. Успешные 28 проверок прежнего контекстного пакета не повторялись и сохранены отдельным доказательством. Снимок прежнего кандидата и отдельные доказательства этого шага хранятся вне репозитория: `D:/PayPlannerRelease/20261024-bank-folder-result/`. Основной план BANK-04 остаётся открытым, прогресс BANK — 0/12 (0%).

## Черновик «Что нового»

**Заголовок:** Понятный результат подгрузки выписок из папки.

**Краткое описание:** В разделе «Деньги → Банк» видны причины ошибок и частичный результат проверки папки.

**Исправлено:** После ручной проверки папки выписок показываются ошибки с именами файлов, первые пять причин и число остальных. Если часть операций уже создана, результат сообщает, что они сохранены, а оставшиеся ошибки требуют внимания. При ошибках результат больше не выдаётся за полный успех.

Номер версии не назначен. Запись не опубликована; `releases.json` не изменён.
