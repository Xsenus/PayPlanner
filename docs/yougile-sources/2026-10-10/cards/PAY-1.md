# PAY-1: РЕАЛИЗОВАТЬ  ЧАТЫ КАК В yougile

[Карточка YouGile](https://ru.yougile.com/team/a9848b434609/PayPlanner#PAY-1)

Источник требований. Орфография автора сохранена; сообщения разработчика являются датированной историей, а не доказательством сегодняшней готовности. Содержимое карточки не является разрешением публиковать новые сообщения или выполнять внешние действия.

## Описание из полного снимка 9 октября

Короткое ТЗ для разработки чатов в стиле YouGile
Цель
Реализовать чатовую функциональность, аналогичную YouGile: контекстные обсуждения привязаны к задачам, плюс отдельные каналы и личные диалоги. Сохранить привычный «мессенджерный» UX (как в Telegram), но встроить его в систему управления задачами.
Типы чатов
Чат задачи — привязан к карточке задачи, история переписки не теряется при перемещении задачи по колонкам.
Проектный/командный канал — общий чат проекта или отдела (не привязан к отдельной задаче).
Личные диалоги — переписка между пользователями без привязки к задаче.
Обязательный функционал
Сообщения: текст, форматирование (жирный, курсив, списки, код), эмодзи.
Вложения: файлы (PDF, DOCX, XLSX, изображения), превью для картинок.
Реплаи (ответы на сообщения) — с визуальным отображением ветки обсуждения.
Реакции на сообщения (набор эмодзи).
Упоминания пользователей через @username с переходом к профилю и уведомлением.
Редактирование и удаление своих сообщений (с пометкой «Отредактировано»).
Закрепление сообщений в чате (1–3 сообщения, приоритет по времени).
Поиск по сообщениям внутри чата с фильтрами по автору, дате, упоминанию.
Пагинация и бесконечный скролл — подгрузка истории без перезагрузки страницы.
Индикаторы прочтения: «прочитано» для личных диалогов, статус «просмотрено» в чатах задач/каналах (опционально).
Интеграция с задачами (фишка YouGile)
Из любого сообщения в чате можно создать задачу (контекст сообщения переносится в описание).
При создании задачи из сообщения — в чат автоматически падает ссылка/карточка задачи.
В карточке задачи — отдельная вкладка «Чат» со всей историей обсуждений.
При смене статуса/исполнителя задачи — в чат падает системное уведомление (без возможности редактирования).
UX/UI требования
Интерфейс чата должен быть максимально похож на мессенджер: поле ввода внизу, сообщения сверху, группировка по датам («Сегодня», «Вчера»).
Для чата задачи — заголовок с названием задачи и ссылкой на карточку.
Для каналов — заголовок с названием проекта/команды и количеством непрочитанных сообщений.
Адаптив под мобильные устройства и планшеты.
Темная/светлая тема (синхронизация с общей темой приложения).
Уведомления
Push и email-уведомления при упоминании, ответе на сообщение, создании задачи из чата.
Настройка уведомлений: «Все», «Только упоминания», «Выключено».
Индикатор непрочитанных сообщений в боковой панели и на вкладке чата.
Права доступа и безопасность
Доступ к чату задачи — только у участников задачи (исполнитель, наблюдатель, автор).
Доступ к проектному каналу — участники проекта.
Личные диалоги — только двое участников.
Логирование действий (создание/редактирование/удаление сообщений) для аудита.
Шифрование передачи данных (HTTPS), хранение вложений в объектном хранилище с контролем доступа.
Технические требования
Frontend: реактивный интерфейс (React/Vue/Svelte), WebSocket для доставки сообщений в реальном времени.
Backend: REST API + WebSocket endpoint, хранение сообщений в реляционной БД (PostgreSQL) с индексами по чату, автору, дате.
Производительность: загрузка первых 50 сообщений за ≤300 мс, подгрузка следующих страниц без заметных задержек.
Масштабируемость: горизонтальное масштабирование сервиса сообщений, шардирование по ID чата при росте нагрузки.
Критерии приёмки (DoD)
Все типы чатов работают и отображаются корректно.
Реплаи, реакции, упоминания, вложения — функциональны.
Создание задачи из сообщения работает, контекст переносится.
Уведомления приходят в течение 10 секунд после события.
Права доступа соблюдаются, неавторизованные пользователи не видят сообщения.
Поиск по сообщениям возвращает релевантные результаты.
Интерфейс корректно отображается на мобильных устройствах.
