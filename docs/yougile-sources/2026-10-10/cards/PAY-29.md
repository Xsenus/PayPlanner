Функционал внутреннего мессенджера в CRM
Основные кнопки интерфейса
- Написать сообщение — создание нового чата или диалога
- Напоминание о сообщениях — уведомления о непрочитанных, отложенные напоминания, пуш-уведомления
- Поиск — по тексту, по сотрудникам, по чатам
- Создать групповой чат — диалог с несколькими участниками
- Прикрепить файл — документы, изображения, скриншоты
- Упомянуть (@) — тег участника с уведомлением
- Звонок — аудио- и видеозвонок (опционально)
- Настройки чата — mute, архив, очистка истории, выход из чата
- Статус (онлайн/офлайн) — индикатор присутствия

Функции мессенджера
Чаты и диалоги
- Личные сообщения между сотрудниками
- Групповые чаты (по проектам, отделам, задачам)
- История переписки с поиском по тексту и датам
- Чтение/непрочитано, индикатор «печатает»

Привязка к CRM
- Привязка чата к сделке, клиенту, задаче — из карточки объекта открывается соответствующий диалог
- Упоминание сущности CRM в чате (ссылка на сделку/клиента)
- Создание задачи из сообщения
- Назначение ответственного прямо из чата

Уведомления
- Непрочитанные счётчиком в шапке
- Push и email-уведомления при отсутствии в CRM
- Настройка «тихого режима» по чатам и часам
- Напоминание о сообщении в выбранное время (snooze)

Файлы и медиа
- Загрузка и просмотр документов
- Превью изображений
- Скачивание из истории чата

Организация и навигация
- Закреплённые чаты
- Архив чатов
- Папки/категории чатов
- Сортировка по дате, по непрочитанным

Безопасность и администрирование
- Разграничение доступа — кто с кем может переписываться
- Логирование переписки (для регламентируемых отраслей)
- Удаление сообщений (с ограничениями по времени/ролям)
- Запрет на удаление истории для админа
- Роли: администратор, участник, наблюдатель

Дополнительно
- Цитирование и ответы на конкретное сообщение
- Редактирование отправленного (с ограничением по времени)
- Эмодзи-реакции на сообщения
- Шаблоны и быстрые ответы
- Экспорт переписки
