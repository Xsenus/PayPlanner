Профиль компании и филиалы в CRM
Модуль «Профиль компании». Логика и структура по аналогии с сервисом КУБ24 (выставление счетов).
Назначение: единый справочник собственных юрлиц/ИП и их филиалов (точек продаж) для автозаполнения реквизитов в счетах, актах, договорах.
Версия: 1.0. Для разработки.
1. Общие принципы
Профиль компании — самостоятельная сущность (справочник «Мои компании»), не привязанная к сделке или делу.
У аккаунта может быть несколько профилей компаний (несколько юрлиц) — как вкладка «Мои компании» в КУБ24.
Один профиль — один ИНН. Филиалы не имеют собственного ИНН и хранятся внутри профиля компании.
Счёт всегда наследует реквизиты от профиля компании или выбранного филиала. Реквизиты вручную в счёте не вводятся.
Автозаполнение реквизитов по ИНН из ЕГРЮЛ/ЕГРИП — ключевой принцип (как в КУБ24).
Банковские реквизиты автозаполняются по БИК.
2. Модель данных
Иерархия: Аккаунт → Профили компаний (1..N) → Филиалы/Точки продаж (0..N у каждого профиля).

4.2. Логика наследования реквизитов
По умолчанию филиал наследует все реквизиты головной компании (наименование с указанием филиала, ИНН, ОГРН, банк).
Переопределяются только те поля, которые явно заполнены на уровне филиала.
В печатной форме счёта наименование выводится: «ООО «X» (Филиал «Y», г. Самара)» — при наличии филиала в счёте.
Удаление филиала запрещено, если по нему есть документы. Доступна только архивация.
5. Алгоритм добавления профиля компании (аналог КУБ24)
Раздел «Профиль компании» → вкладка «Мои компании» → кнопка «Добавить». Доступно только администратору (или на платном тарифе, по модели КУБ24).
Шаг 1. Пользователь выбирает ОПФ (ООО / ИП / самозанятый / АО) и систему налогообложения → «Сохранить».
Шаг 2. Открывается форма создания: единственное обязательное поле — ИНН.
Шаг 3. Система по ИНН запрашивает данные ЕГРЮЛ/ЕГРИП и автоматически заполняет: наименование, КПП, ОГРН, юр. адрес, дату регистрации.
Шаг 4. Пользователь проверяет и дополняет: банковские реквизиты (БИК → автоподстановка банка и корсчёта), телефоны, email.
Шаг 5. Настройка СНО: подтверждение выбранной системы, ставки НДС, признака плательщика НДС.
Шаг 6. Загрузка логотипа, печати, подписи (опционально, можно позже).
Шаг 7. Назначение подписанта (по умолчанию — руководитель из ЕГРЮЛ).
Шаг 8. «Сохранить» → профиль активен, появляется в справочнике «Мои компании» и в выборе продавца при выставлении счёта.
Валидации на шагах 2–4:
ИНН: 10 цифр для юрлиц, 12 для ИП; проверка контрольного числа. При ошибке — сообщение «Проверьте ИНН».
Если организация в ЕГРЮЛ не найдена или ликвидирована — предупреждение, ручной ввод реквизитов разрешён.
Запрет создания второго профиля с тем же ИНН в пределах аккаунта.
БИК: 9 цифр, банк находится по справочнику; при отсутствии — ручной ввод.
6. Алгоритм добавления филиала
Открыть профиль компании → блок «Филиалы / Точки продаж» → «Добавить филиал».
Заполнить: название, тип точки, адрес, телефон.
При необходимости: переопределить банковские реквизиты, подписанта, КПП.
При необходимости: задать префикс нумерации документов (например, «Ф1-»).
«Сохранить» → филиал появляется в выпадающем списке при выставлении счёта.

8. Связь с модулем «Счёт»
При создании счёта поле «Продавец» = выбор профиля компании (или филиала) из справочника «Мои компании».
В печатную форму счёта подставляются: наименование, ОПФ, ИНН, КПП, адрес, банковские реквизиты, подписант, логотип/печать/подпись.
Изменение реквизитов в профиле НЕ переписывает уже созданные документы (снимок реквизитов фиксируется в счёте на момент создания).
СНО профиля определяет расчёт НДС в счёте: вариант «в том числе / сверху / без налога» и ставку по умолчанию.
Наименование и реквизиты покупателя — из модуля «Контрагенты», не из профиля компании.

Физическое удаление профиля запрещено — только архивация (защита истории документов).
10. Жизненный цикл профиля
Черновик — создан, реквизиты заполнены не полностью; недоступен для выставления счетов.
Активен — все обязательные поля заполнены; доступен для документов.
Архив — не отображается в выборе «Продавец» при создании новых счетов; старые документы сохраняются.
11. Критерии приёмки
Профиль создаётся за 4 действия: ОПФ+СНО → ИНН → проверка автозаполнения → сохранить.
Реквизиты по ИНН подтягиваются из ЕГРЮЛ/ЕГРИП, банк по БИК, без ручного ввода.
При выставлении счёта реквизиты продавца не вводятся — только выбор компании/филиала.
Филиал наследует реквизиты и переопределяет только явно заданные поля.
Нумерация счётов не дублируется, поддерживает префиксы филиалов и сквозной режим.
Изменение реквизитов не влияет на ранее созданные документы.
Логотип/печать/подпись корректно отображаются в печатной форме PDF.
Нельзя удалить профиль/филиал с существующими документами — только архивация.
