## Доступность и права

Клавиатурный фокус: [меню клиента](PAY-32-keyboard-focus.png), [быстрый доступ дела](PAY-21-keyboard-focus.png). Enter переключает разделы и раскрывает/сворачивает дополнительные сведения и фильтры; фокус остаётся на переключателе. Активные пункты имеют `aria-current=page`. [Свёрнутые фильтры](PAY-19-journal-collapsed-1440.png) показывают действующие ограничения.

[Исполнитель без просмотра задач и финансов](restricted-executor-events.png): закрытые вкладки и кнопки отсутствуют, при открытии событий запрашиваются только судебные события. Прямые API отказывают в закрытых разделах. Пять ролей и восстановление исходных прав описаны в JSON доказательств.

[Снимок настройки календаря PAY-37](PAY-37-calendar-setting.png) — отдельный ответ поддержки, опубликованный по узкому разрешению владельца; [текст и подтверждение](../../yougile-pay-37-support-reply-2026-10-12.md). Он не входит в проверку шести экранов.
