## Что изменилось

Экран связан с текущими пользователем, входом, ролью и разрешениями. Смена владельца сбрасывает чувствительную форму и старые продолжения; обычное обновление токена не перезагружает форму. Ответ профиля принимается только для ожидаемого пользователя. Гость не загружает личные данные. Ошибка загрузки не разрешает сохранить пустую неподтверждённую форму; явное обновление остаётся доступным.

Обновление профиля принимает последний набор параллельных чтений. Сохранение отменяет принятие предшествующих чтений. Набранные контакты сохраняются при обновлении фото, способов входа и при завершении старой записи после смены прав; остальные поля обновляются из свежего профиля. Новый текст, введённый во время запроса, не подменяется ответом. Резервирование записи сохраняется для того же пользователя при смене роли и снимается после окончания запроса; другой пользователь не блокируется. После старой записи текущий доступный экран перечитывает свои данные.

Контакты, напоминания, фото, пароль и способы входа используют существующее владение асинхронными действиями. Перед каждым последующим запросом, принятием подтверждения, сообщением или переходом проверяется исходный владелец. Старое подтверждение не отвязывает способ входа у нового пользователя. Фото из старого чтения файла или закрытого окна обрезки не начинает новую загрузку. Обычные текущие отказы остаются видимыми, неизвестный исход не запускает автоматическую повторную запись. Частичная ошибка сохранения поясняет, какие данные профиля уже приняты сервером.

Часовой пояс записывается обычным сохранением только после явного изменения поля. Отсутствующая настройка инициализируется ранее проверенным отдельным маршрутом, который не заменяет существующее значение. Ошибку чтения нельзя принять за отсутствие по одному упоминанию 404 в тексте отказа. При неподтверждённых настройках показано пояснение; сохранение контактов не записывает временный пояс браузера. Напоминания после ошибки чтения можно сохранить только после явного выбора. Уже сохранённые настройки, документы, задачи и финансовая история автоматически не меняются.

## Пограничный случай внешнего входа

Проверка статуса внешнего входа может потребить завершённый запрос на сервере. Поэтому она не перекрывается с другой записью профиля; одновременно выполняется не более одной проверки статуса.
