# Роадмап проверки дат и времени

Цель: привести все даты и время в PayPlanner к единому правилу, проверить проблемные места и закрыть риск сдвига времени у пользователей из разных регионов.

## Базовое правило

- [ ] Точные события хранить как UTC.
- [ ] Показывать точные события пользователю через `timezoneId` из профиля.
- [ ] Локальные даты без времени не переводить как UTC-момент.
- [ ] Календарные диапазоны строить по локальному дню пользователя.
- [ ] Внешние календари должны получать точное время и timezone события/исполнителя.
- [ ] Убрать фиксированные смещения вроде `+07:00`.
- [ ] Не использовать timezone браузера там, где правило требует timezone профиля.

## Типы дат

- [ ] `InstantUtc`: точный момент времени, например создание, обновление, срок задачи, судебное заседание.
- [ ] `LocalDate`: дата без времени, например дата счета, дата акта, дата рождения, дата платежа.
- [ ] `LocalDateTime + TimeZoneId`: пользователь вводит локальное время, система переводит его в UTC.
- [ ] `System/Audit Time`: техническое время системы, хранится UTC, показывается через timezone пользователя.
