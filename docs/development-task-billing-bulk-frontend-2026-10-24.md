## Подготовленный механизм

Одно общее окно открывается из панели выбранных задач журнала и списка задач дела. При первом открытии фиксируются только выбранные на странице ID и исходные `updatedAt` без преобразования дат; отсутствующий token передаётся явным `null`. Набор не расширяется при смене текущего выбора. Новый набор создаётся только после отдельного подтверждения.

Целевые классы — платная и неоплачиваемая/внутренняя. По умолчанию завершённые исключены; их включение требует явной отметки. Предварительные подсказки о счёте, выплате и договорном учёте не подменяют построчную проверку сервера. Счета, выплаты, договорные связи/снимки, статус, результат, файлы, суммы и другие поля операция не сохраняет.

Используется один существующий `POST /tasks/bulk`, без отдельных сохранений каждой задачи. Payload содержит только `ids`, `billingClassification`, `includeCompleted` и точную карту `expectedUpdatedAtById`. Ответ принимается только при точном покрытии отправленных ID и согласованности счётчиков/исходов/причин. Старые status/assignee bulk-ответы без `items` сохраняют совместимость, но не считаются успешным ответом финансового действия.

Отмена, закрытие и ошибка сохраняют фиксированный набор и параметры. Ожидающий запрос защищён от двойной отправки, закрытия Escape и параллельных массовых изменений; вкладки/возврат/редактирование дела временно заблокированы. Смена сотрудника, дела, фильтра/страницы или отзыв общих прав блокируют новое отправление из прежней области. Поздний ответ не обновляет другую область. Сведения прежнего сотрудника скрываются.

Изменённые и уже совпадающие строки повторно не отправляются. После конфликта, пропуска или неподтверждённого ответа необходимо свежее чтение оставшихся задач и новое явное подтверждение. Читаются только зафиксированные оставшиеся ID, максимум четыре запроса одновременно. Недоступность одной строки не блокирует остальные: её исходный результат и сообщение чтения сохраняются отдельно, повтор включает только успешно прочитанные строки. Ошибка чтения не выдаётся за результат изменения. Неизвестная сетевая ошибка останавливает дальнейшее наращивание чтений.

Обе карточки используют прежнюю общую модель и административный переключатель. Событие изменения вызывает свежее чтение открытой карточки и обновляет только её поля учёта; несохранённое название и прочие поля формы не пересохраняются. В деле обновляется существующая страница/сводка задач, без полного перезапуска страницы дела, который уничтожил бы построчный итог.
