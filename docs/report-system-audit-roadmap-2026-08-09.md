# Полный аудит отчетов и печатных шаблонов

Дата начала: 2026-08-09

## Цель

Проверить все отчеты и печатные документы PayPlanner: состав данных, фильтры, права доступа, заполнение шаблонов, редактирование, историю версий, экспорт, печать и PDF. Результат должен подтверждаться автоматическими тестами и визуальной проверкой сформированных документов.

## Общие критерии готовности

- [ ] Составлен полный реестр доступных пользователю отчетов и печатных документов.
- [ ] Для каждого отчета проверены данные, пустое состояние, фильтры, часовой пояс и права доступа.
- [ ] Для каждого поддерживаемого формата проверены CSV, Excel, PDF и печатная версия.
- [ ] Все редактируемые шаблоны валидируются до сохранения и имеют доступную историю версий с восстановлением.
- [ ] Итоговые PDF сформированы на репрезентативных данных, отрисованы в PNG и просмотрены на обрезку, наложения, переносы и читаемость.
- [ ] Пройдены профильные frontend/backend тесты, TypeScript, сборка, проверка кодировки и локальной БД.
- [ ] Для видимых изменений подготовлены отдельные записи в «Что нового».
- [ ] Каждое самостоятельное исправление оформлено отдельным коммитом с русским сообщением.

## Зафиксированные риски

- Настройки шаблонов счета и договора хранят только текущее состояние; восстановимой истории версий нет.
- Шаблон акта формируется отдельным движком, но не имеет равного интерфейса настройки.
- Аналитические отчеты используют несколько путей экспорта; паритет полей и фильтров между экраном, CSV, Excel, PDF и печатью требует проверки по каждому виду.
