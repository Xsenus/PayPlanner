## Текущее состояние

Счет и договор имеют редактируемые HTML-шаблоны в системных настройках, но сохранение перезаписывает текущее значение. Журнал действий по отдельным документам не содержит восстановимого снимка шаблона. Акт использует отдельный встроенный шаблон без равного интерфейса редактирования.

## Definition of done

Администратор видит историю каждого редактируемого шаблона, может открыть любую версию и восстановить ее без потери последующих записей. Генерация документов использует выбранную актуальную версию, а одинаковое повторное сохранение не раздувает историю.
