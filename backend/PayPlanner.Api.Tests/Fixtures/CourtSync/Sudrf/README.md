# Обезличенные ответы СУДРФ

Файлы в этом каталоге являются синтетическими копиями структуры публичных HTML-ответов СУДРФ.

- ФИО, номера дел, идентификаторы, названия судов и организаций заменены тестовыми значениями.
- Файлы не содержат персональных данных и не получаются из сети во время тестов.
- Структура таблиц и полей сохранена только в объёме, необходимом для проверки контракта парсера.
